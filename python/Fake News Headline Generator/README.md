# 📰 Fake + Funny News Headline Generator

> **Generate hilarious, over-the-top, completely fake news headlines with a single click!** 🤣
> Perfect for learning Python, experimenting with randomization, or just having a good laugh.

---

## ✨ Features

* 🎭 Multiple headline categories

  * Politics
  * Bollywood
  * Sports
  * Tech
  * Local
  * Random Mix

* 📝 Multiple headline templates for varied outputs

* 🔄 Smart no-repeat logic (avoids generating the same headline twice in a row)

* 📦 Batch headline generation

* 🌈 Colored terminal output (using `colorama` if installed)

* 📊 Fun credibility score (always suspicious 😆)

* ❤️ Random likes & shares

* #️⃣ Auto-generated viral hashtags

* 💾 Save generated headlines to a timestamped `.txt` file

* 📂 External JSON word bank so you can easily add your own content without editing the Python code

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/klsatapathy/data-science-core-toolkit.git
```

### 2. Navigate to the project

```bash
cd data-science-core-toolkit/python/"Fake News Headline Generator"
```

### 3. (Optional) Install Colorama

```bash
pip install colorama
```

### 4. Run the program

```bash
python headline_generator.py
```
